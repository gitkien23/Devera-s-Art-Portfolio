# De Vera's Art Portfolio System

## Deploy with Vercel

1. Extract this ZIP.
2. Put `index.html` and this README in the root of a GitHub repository.
3. In Vercel, create a project by importing that GitHub repository. No build command is needed; the site is static HTML.

## Important

This version is browser-only. Accounts, artwork, and approvals are saved in each visitor's browser and are not shared across devices. Passwords are not securely stored. This package does not include a server backend and should not be used for real authentication or private data.
